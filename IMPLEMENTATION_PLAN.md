# Construction and release checklist

One complete free product; construction order is not a roadmap of product phases.

1. Document confirmed decisions and $0 replacements; establish tokens and ownership boundaries.
2. Scaffold static app, auth configuration, local persistence, cloud policies, quotas, and atomic revisions.
3. Source-preserving import preview/commit/issues/tombstones and browsing before organization.
4. Manual collections/subcollections, details, notes, tags, intent, state, exact search, filters/sorts, and rediscovery.
5. Device-local model caching, related search, evidence-derived grouping, proposal publication, and pause/retry.
6. Conflict/offline recovery, export/restore, account/library deletion, history, safe sign-out.
7. Reference-inspired responsive visual design and accessible interaction.
8. Meaningful parser, database and browser checks; private model/quality/performance evaluation.
9. Deploy to free hosting, configure Google and deletion, verify real accounts/data isolation, establish operator/contact/legal details, rehearse recovery, then activate bounded admissions.

See TESTING.md for measured local verification and OPERATIONS.md for external prerequisites. Do not declare live production complete from source/build success.
